# VK Music Downloader

Расширение для Chrome / Opera / Opera GX / Edge / Brave (Chromium ≥ 111). Добавляет кнопку скачивания справа от названия каждого трека на vk.ru.

## Установка

1. Откройте страницу расширений: `opera://extensions` (Opera GX), `chrome://extensions` или `edge://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку (`VKDownloadMusic`).
4. Обновите вкладку VK (F5) и откройте, например, https://vk.ru/audios482028774.

## Использование

Нажмите на значок ↓ рядом с названием трека. Кнопка покажет прогресс, после чего браузер сохранит файл `Исполнитель - Название.mp3` (с тегами и обложкой). Плеер VK при этом не запускается.

## Как это работает

- Ссылку на трек запрашивает через `al_audio.php?act=reload_audios` (с вашими cookies) и расшифровывает так же, как клиент VK.
- Трек отдаётся как HLS (`.m3u8`, сегменты MPEG-TS, часть сегментов зашифрована AES-128). Расширение скачивает сегменты, расшифровывает их через WebCrypto, извлекает MP3-поток и склеивает в файл. Перекодирования нет — качество исходное.
- Добавляются теги ID3v2.3: название, исполнитель, обложка.
- Расширению не нужны никакие разрешения (`permissions`), оно работает только на vk.ru / vk.com, ничего никуда не отправляет.

## Структура

- `manifest.json` — манифест MV3, скрипты выполняются в контексте страницы (`world: MAIN`).
- `src/unmask.js` — расшифровка ссылок `audio_api_unavailable.mp3?extra=...`.
- `src/hls.js` — плейлист, сегменты, AES-128, демультиплексор TS, ID3.
- `src/main.js` — поиск треков на странице, кнопка, сохранение файла.
- `src/style.css` — стили кнопки.

## Если перестало работать

VK периодически меняет вёрстку и алгоритм ссылок. Строки нового интерфейса ищутся по `data-testid="MusicTrackRow"`, алгоритм расшифровки лежит в `src/unmask.js`. Ошибку покажет красная кнопка (подсказка при наведении) и консоль браузера (`[VK Music Downloader]`).
